# Migrations

> **Migration** é uma forma de manter o **versionamento do banco de dados**, registrando as alterações feitas na estrutura do banco ao longo do desenvolvimento da aplicação.

- Permite controlar as alterações do banco.
    
- Mantém o banco sincronizado com o código da aplicação.
    
- Facilita a criação e configuração de novos ambientes.
    
- Evita depender de alterações feitas manualmente no banco.
    
- Cada alteração pode ser registrada em uma versão.
    

## 1. Versionamento do banco

> Assim como o código da aplicação possui versões, as alterações do banco também podem ser versionadas.

Por exemplo:

```text
V1 → Criação das tabelas
V2 → Adição de uma coluna
V3 → Criação de um índice
V4 → Alteração de uma tabela
```

Dessa forma, conseguimos saber **quais alterações já foram aplicadas** e quais ainda precisam ser executadas.

### 1.1 Exemplo

Imagine que inicialmente temos:

```sql
CREATE TABLE usuarios (
    id BIGINT PRIMARY KEY,
    nome VARCHAR(100)
);
```

Depois precisamos adicionar um email:

```sql
ALTER TABLE usuarios
ADD COLUMN email VARCHAR(255);
```

Essa alteração pode ser registrada em uma nova migration:

```text
V1__criar_tabela_usuarios.sql
V2__adicionar_email.sql
```

Assim, a ferramenta de migration consegue executar as alterações na ordem correta.

## 2. Ferramentas de Migration

> Existem ferramentas que automatizam o controle e a execução das migrations.

Algumas ferramentas conhecidas são:

- **Flyway**
    
- **Liquibase**
    

### 2.1 Flyway

> **Flyway** é uma ferramenta utilizada para controlar e executar migrations de banco de dados.

As migrations normalmente são arquivos SQL versionados:

```text
V1__criar_usuario.sql
V2__criar_livro.sql
V3__adicionar_email.sql
```

O Flyway verifica quais migrations já foram executadas e executa somente as que ainda não foram aplicadas.

### 2.2 Liquibase

> **Liquibase** também é uma ferramenta para controlar e versionar alterações no banco de dados.

Ela permite definir as alterações utilizando formatos como:

- SQL
    
- XML
    
- YAML
    
- JSON
