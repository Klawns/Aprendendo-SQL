#db 
# 1. O que são

Functions são **rotinas armazenadas no banco de dados que recebem valores, processam esses valores e retornam um resultado**.

Uma forma simples de pensar:

```text
Entrada
   ↓
Function
   ↓
Resultado
```

Por exemplo:

```text
100 + 50
  ↓
Function
  ↓
150
```

A principal diferença em relação a uma Procedure é que a Function  foi feita para **produzir um valor que pode ser utilizado dentro de uma expressão SQL**.

### Exemplo da vida real

Em um sistema financeiro, podemos ter uma Function para calcular uma taxa:

```text
valor = R$ 1.000
taxa = 5%

Function
   ↓
R$ 50
```

A aplicação pode utilizar esse resultado diretamente em uma consulta.

---

# 2. Sintaxe

Estrutura básica no MySQL:

```sql
CREATE FUNCTION <func-name>(<parametros>)
RETURNS <tipo-de-dado-retornado>
BEGIN
    -- bloco de código

    RETURN <valor>;
END;
```

Exemplo:

```sql
CREATE FUNCTION calcular_desconto(
    valor DECIMAL(10,2),
    percentual DECIMAL(5,2)
)
RETURNS DECIMAL(10,2)
BEGIN
    RETURN valor * percentual / 100;
END;
```

Agora podemos utilizar:

```sql
SELECT calcular_desconto(1000, 10);
```

Resultado:

```text
100.00
```

---

# 3. Parâmetros

Assim como Procedures, Functions podem receber parâmetros.

Exemplo:

```sql
CREATE FUNCTION dobrar(valor INT)
RETURNS INT
BEGIN
    RETURN valor * 2;
END;
```

Chamando:

```sql
SELECT dobrar(10);
```

Resultado:

```text
20
```

Nesse caso:

```text
10
 ↓
dobrar()
 ↓
20
```

---

# 4. RETURN

Toda Function precisa retornar um valor compatível com o tipo declarado em:

```sql
RETURNS
```

Exemplo:

```sql
CREATE FUNCTION somar(a INT, b INT)
RETURNS INT
BEGIN
    RETURN a + b;
END;
```

Aqui:

```text
RETURNS INT
```

significa:

> Essa Function retorna um `INT`.

E:

```sql
RETURN a + b;
```

define o valor que será devolvido.

# 5. Utilizando Functions em consultas

Uma das principais vantagens das Functions é poder utilizá-las dentro de consultas SQL.

Por exemplo:

```sql
SELECT calcular_desconto(1000, 10);
```

Também podemos utilizá-las em uma tabela:

```sql
SELECT
    name,
    price,
    calcular_desconto(price, 10) AS discount
FROM products;
```

Resultado:

```text
name       | price  | discount
-----------|--------|---------
Notebook   | 5000   | 500
Mouse      | 200    | 20
Teclado    | 300    | 30
```

A Function é executada para cada linha retornada pela consulta.

### Exemplo da vida real

Imagine uma loja que possui uma regra de cálculo de desconto.

Em vez de repetir:

```sql
price * 10 / 100
```

em várias consultas, podemos criar:

```sql
calcular_desconto(price, 10)
```

Isso deixa a consulta mais legível e centraliza o cálculo.

# 6. Functions x Procedures

As duas são rotinas armazenadas no banco, mas possuem propósitos diferentes.

### Function

Normalmente:

```text
Recebe dados
   ↓
Calcula/processa
   ↓
Retorna um valor
```

Pode ser utilizada dentro de uma consulta:

```sql
SELECT minha_function(...);
```

### Procedure

Normalmente:

```text
Recebe dados
   ↓
Executa uma rotina
   ↓
Pode realizar várias operações
```

É chamada com:

```sql
CALL minha_procedure(...);
```

### Comparação

```text
Function
→ retorna um valor
→ pode ser usada em expressões SQL
→ SELECT minha_function(...)

Procedure
→ executa uma rotina
→ pode realizar várias operações
→ CALL minha_procedure(...)
```

### Exemplo

Function:

```sql
SELECT calcular_desconto(1000, 10);
```

Procedure:

```sql
CALL realizar_pagamento(1, 500);
```

Uma forma fácil de memorizar:

```text
Function
→ "Me dê um resultado."

Procedure
→ "Faça esse processo."
```

# 7. Functions e alteração de dados

Functions são pensadas principalmente para **calcular e retornar valores**.

Por exemplo:

```text
calcular desconto
calcular imposto
formatar informação
converter valores
verificar uma condição
```

Já Procedures são mais apropriadas quando precisamos executar uma sequência de operações, como:

```text
criar pedido
atualizar estoque
registrar pagamento
realizar transferência
```

No MySQL existem restrições importantes sobre o que uma Stored Function pode fazer. Por isso, não devemos pensar em Function como uma Procedure "que retorna algo".

A ideia principal é:

```text
Function
→ usada como parte de uma expressão

Procedure
→ usada para executar um processo
```

# 8. Funções determinísticas

Uma Function é **determinística** quando, para os mesmos valores de entrada, ela sempre produz o mesmo resultado.

Exemplo:

```sql
CREATE FUNCTION dobrar(valor INT)
RETURNS INT
DETERMINISTIC
BEGIN
    RETURN valor * 2;
END;
```

Se executarmos:

```sql
SELECT dobrar(10);
```

sempre teremos:

```text
20
```

Porque:

```text
dobrar(10) → 20
dobrar(10) → 20
dobrar(10) → 20
```

### Exemplo não determinístico

Uma função que utiliza o horário atual não possui necessariamente o mesmo resultado:

```sql
NOW()
```

Por exemplo:

```text
agora → 14:00
alguns segundos depois → 14:01
```

Logo, o resultado depende de algo que mudou.

---

# 9. O que significa DETERMINISTIC?

Podemos declarar:

```sql
DETERMINISTIC
```

quando sabemos que:

```text
mesma entrada
     ↓
mesmo resultado
```

Exemplo:

```sql
CREATE FUNCTION calcular_dobro(valor INT)
RETURNS INT
DETERMINISTIC
BEGIN
    RETURN valor * 2;
END;
```

Já uma Function que depende de informações que podem mudar, como horário atual ou dados externos, pode ser considerada não determinística.

### Importante

**Determinística não significa "segura" ou "não altera dados".**

O conceito é especificamente:

> **mesmas entradas → mesmo resultado**
